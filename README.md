# Ruhi's Birthday Surprise

A personal birthday-surprise website for Ruhi, with a countdown for **12:00 AM on 10 September 2026**.

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

To preview the surprise before the birthday date, add `?preview=1` to the URL:

```text
http://127.0.0.1:5500/index.html?preview=1
```

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Push this project to its `main` branch.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, then choose `main` and the `/ (root)` folder.
5. Save. GitHub will provide the public website link.

## Privacy note

This project contains personal photos, videos, voice notes, and songs. Anyone with access to a public repository or its deployed site can access those files. Use a private GitHub repository unless you are comfortable sharing them publicly.
